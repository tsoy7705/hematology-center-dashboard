Полное описание продукта — в [PRD.md](PRD.md).

## О файле `index.html`

Это самостоятельная HTML-страница (без сборки, без зависимостей), изначально опубликованная как Claude Artifact с общим хранилищем данных в реальном времени (`db capability`).

**Важно:** общее хранилище данных работает только при открытии страницы внутри claude.ai. При статическом хостинге (например, GitHub Pages) страница автоматически переходит в демонстрационный режим на локальных примерах — данные не сохраняются и не синхронизируются между пользователями.

Рабочая версия с общим хранилищем: см. ссылку в PRD.md.
